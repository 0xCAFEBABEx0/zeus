# Agent instructions

Project documentation lives in [docs/](./docs/README.md). Read the relevant document before changing code, and follow [docs/DEVELOPMENT_WORKFLOW.md](./docs/DEVELOPMENT_WORKFLOW.md) for branches, commits and pull requests.

## Rules

- When the documentation and the existing code disagree, follow the conventions of the code, and list every discrepancy you found in your final reply.
- When changing the website's interface (`apps/web`) or CMS admin components, follow the contributor expectations in [docs/ACCESSIBILITY.md](./docs/ACCESSIBILITY.md) and update its known limitations when a change fixes or introduces a barrier.
